✦ Milestone 1 — Manual Oficial de Marca

DOReMI SOLFÁ Móveis

Guia definitivo de identidade visual para a modernização da aplicação em React. Este kit reúne os logotipos oficiais, os tokens de cores harmonizados com a essência do projeto acadêmico da UFF, o sistema tipográfico e os padrões visuais para todos os componentes.

🏷️ 1. Aplicação dos Logotipos Oficiais

🎨 2. Paleta de Cores Oficial (Design Tokens)

Cores extraídas da identidade visual, combinando o acolhimento do mobiliário com alto contraste para e-commerce.

#1F563E
Verde-Floresta Cor Primária da Marca Extraído do estofado do sofá. Utilizado para botões principais (CTA), Navbar e badges principais. Substitui: Verde de tabela (#228855) da AD1.
#B34229
Terracota Artesanal Cor de Destaque & Preços Extraído da tipografia do logotipo. Utilizado para valores de produtos, links ativos e elementos de atenção. Substitui: Vermelho puro (#E53646) da AD1.
#DFA034
Mostarda Quente Cor de Acento Extraído da almofada do sofá. Utilizado para selos de novidades, estrelas de avaliação e detalhes visuais. Novo elemento de contraste acolhedor.
#FAF8F5
Off-White / Creme Suave Fundo Geral (Background) Base acolhedora para leitura limpa e confortável, sem o desgaste visual do branco frio. Substitui: Amarelo-esverdeado (#E6F0B5).
#FFFFFF
Branco Puro Superfície de Cards & Modais Garante foco total na fotografia dos móveis e clareza na visualização das especificações técnicas. Substitui: Amarelo forte (#FFFFBB).
#E8E4DC
Borda Areia Divisores & Bordas Linhas sutis para separação de seções, caixas de input e contornos de cards. Substitui: Bordas azuis rígidas (#226699).
#1C2521
Carvão Escuro Texto Principal Preto aquecido de altíssimo contraste (acessibilidade AAA) para títulos e descrições. Substitui: Azul escuro (#000066).
#64746D
Cinza Natural Texto Secundário Para medidas técnicas (AxLxP), legendas de tecidos, parcelamentos e placeholders. Leitura suave e equilibrada.

⚙️ 5. Configuração Técnica Oficial (Tailwind CSS)

Tokens definitivos prontos para serem inseridos no tailwind.config.js do projeto.

// tailwind.config.js — Configuração Definitiva da Marca

export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {
      colors: {
        brand: {
          primary: '#1F563E',         // Verde-Floresta do Sofá (Navbar / Botões Principais)
          'primary-hover': '#16402E',
          highlight: '#B34229',       // Terracota da Tipografia (Preços / Badges / Destaques)
          'highlight-hover': '#96351F',
          accent: '#DFA034',          // Mostarda da Almofada (Acentos / Novidades)
          'accent-hover': '#C58B28',
          bg: '#FAF8F5',              // Fundo Principal (Off-White / Creme Suave)
          surface: '#FFFFFF',         // Superfície de Cards e Modais (Branco Puro)
          muted: '#F3EFEA',           // Fundo Areia Secundário
          border: '#E8E4DC',          // Borda Areia Suave
          dark: '#1C2521',            // Texto Principal (Carvão Escuro)
          textMuted: '#64746D',       // Texto Secundário (Cinza Médio Natural)
        }
      },
      fontFamily: {
        serif: ['"Marcellus"', 'Georgia', 'serif'],
        sans: ['"Plus Jakarta Sans"', 'system-ui', 'sans-serif'],
      }
    },
  },
  plugins: [],
};
